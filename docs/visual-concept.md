# 视觉概念草案：鲸落星海

## 设计命题

网站面向英才实验学院在校生、准备加入科协的学生和对外访客。首页的任务不是平铺所有功能，而是让访客跟随一只座头鲸，从星空与海面逐步下潜，在探索过程中进入科协的知识、竞赛、记忆、日常和精神世界。

滚动是一次下潜。座头鲸只在关键转场出现，鲸歌、气泡、光束和远处轮廓在其他章节延续它的存在，避免把鲸鱼变成重复出现的装饰物。

## 视觉语言

### 色彩

- 星空蓝 `#061A3A`：海面、夜空和品牌背景。
- 海洋蓝 `#0B5B8E`：浅海、水体和主要交互。
- 深渊蓝 `#031018`：深海章节与页脚。
- 月光白 `#F5FBFF`：主文字、鲸鱼高光和水面反射。
- 星芒金 `#F2C66D`：星辰、荣誉与关键节点。
- 海草绿 `#0E4B3B`：浅海生态和辅助状态。

金色只出现在荣誉、星辰和少量重点操作中。蓝色不单独承担全部层次，白色、墨绿和金色共同维持综合色彩。

### 字体

- 品牌标题：现代中文衬线字体，承担梦幻与叙事感。
- 正文与导航：清晰的中文无衬线字体，保证长文和操作效率。
- 水深、年份和坐标：等宽字体，建立科学观测感。

### 标志性元素

整站唯一的强视觉动作是“鲸鱼带领页面下潜”。右侧水深标尺承担章节导航和当前位置提示，属于信息结构，不是装饰。

## 首页章节

1. `00m 海面`：鲸鱼跃出星空下的海面，展示协会全称和“随鲸下潜”入口。
2. `80m 知识潮汐`：海草森林与生物荧光节点组成知识网络，进入知识库分类和精选文章。
3. `300m 竞赛航线`：声呐圆环和洋流路径表现竞赛方向、经验与成果。
4. `900m 时间回声`：新闻作为最新信号，大事记沿水深形成时间线。
5. `1800m 同行灯火`：深海科研舱、照片舷窗、成员与便签形成温暖的科协日常。
6. `4000m 海底星图`：鲸歌点亮金色荣誉节点，以精神理念和竞赛成果完成星空与海洋的呼应。

### 80m 知识潮汐交互

知识库分类不再使用固定圆形入口，而是组成一片可拖拽的线描水母知识网络。水母只保留伞盖轮廓和少量触须，分类标题与文章数量独立位于形象下方并随节点移动，不把文字挤入生物内部。所有节点保持相近尺度，避免暗示不存在的分类层级。

- 图谱没有可见外框、内圈或中心枢纽，仅使用不可见安全边界和碰撞力把节点留在可操作海域内。
- 分类之间使用稳定伪随机拓扑：先保证全部节点连通，再补充少量跨节点连接；每个节点通常维持两至三条连接，最多四条。连接关系不因刷新或分类顺序变化而随机跳变。
- 连接线采用低透明度蓝白实线。悬停或聚焦时轻微强调当前节点及其邻接关系；拖拽时仅高亮周围连接线和直接相邻节点，并通过弹簧力轻微牵动邻居。拖拽使用冷白青高亮，点击选中使用星芒金高亮。
- 空闲状态下，分类水母从不规则散点位置出发，受微弱洋流、连接弹力和避让力影响缓慢漂移，不形成圆环或整齐队列。指针悬停或键盘聚焦时，当前水母只减速而不改变图谱结构。
- 水母伞盖、触须和微光使用同一呼吸周期：伞盖收缩时光晕略亮并收束，舒展时光晕变淡并扩散；各节点使用错开的动画相位，避免同步律动。
- 拖拽只改变节点位置和连接关系的空间表现，不直接进入分类。拖拽结束后，未选中的水母重新加入洋流。
- 点击分类后，仅固定当前水母的位置并继续伞体律动；标题、线描轮廓和相连实线使用星芒金高亮，其他节点保持低速漂移。
- 文章列表从水母周围可用空间最大的方向出现。桌面端依次尝试右、左、右下和左下位置，并把列表区域作为其他节点的临时碰撞障碍；移动端使用图谱下方预留的潮汐托盘，列表不得覆盖当前水母。
- 列表固定预留五行高度，每条文章以约 `110–140ms` 的间隔逐条显现。每批最多五篇；超过五篇时提供“换一批”，按稳定游标顺序切换，避免随机重复。
- 点击文章进入文章详情，点击“进入分类”才进入分类页。再次点击已选水母、点击空白海域或按 `Esc` 关闭列表并解除定锚。
- 章节底部的精选文章条仅在图谱空闲时显示；分类被选中后淡出，避免与上下文文章列表争夺注意力。
- 图谱不接管滚轮缩放，不劫持首页自然下潜。触摸端只在明确拖拽节点后捕获指针。
- `prefers-reduced-motion` 下停止漂流、律动和逐条显现，保留静态节点、选中高亮和完整列表。

### 300m 竞赛航线交互

竞赛分类不再使用纵向列表，而是作为深海水听站中的回波目标分布在圆形扫描区域内。桌面端由左侧声纳承担分类选择，右侧上方保留紧凑章节标题，右侧下方展示稳定映射的星座信号图；移动端依次排列标题、声纳与文章星图。整章的主要动作链为“扫描、命中、锁定、点亮”，不叠加无关的科幻仪表装饰。

- 声纳最多展示七个竞赛分类。分类坐标由稳定伪随机槽位生成，刷新和分类排序变化不会导致位置跳动；桌面端与移动端分别使用适配字号的安全间距，标题不得重合。
- 声纳圆周显示克制的方位刻度与 `000° / 090° / 180° / 270°` 标记，中心发射器周期性向外扩散低频探测波。少量无文字、不可点击的暗淡杂波点用于维持深海回波密度，但不得与真实分类混淆。
- 扫描指针以十秒为周期匀速旋转，由冷白扫描线、约 `25–35°` 的青色扇形拖尾和两道快速消散的弧形残影组成。扫描经过分类节点时，节点短暂出现星芒金描边、扩散环和光晕；扫描反馈不改变当前选择。
- 点击分类只锁定该竞赛航线并切换文章信号，不直接导航。选中后从声纳中心向目标绘制细金色方位线，目标持续显示金色状态与 `AZ 方位角 · LOCKED` 读数；再次点击、按 `Esc` 或使用关闭按钮返回精选模式。
- 未选择分类时，文章区域查询已发布且标记为精选的竞赛文章；选中后查询该分类下的已发布文章。两种模式每批最多七篇，超过七篇时提供“换一批”，并按稳定游标循环切换。
- 星图预设白羊、金牛、双子、巨蟹、狮子、处女、天秤、天蝎、射手、摩羯、水瓶和双鱼十二种抽象轮廓。分类模式根据分类 `slug` 固定映射星座；精选模式根据批次游标稳定切换，组件重渲染不得改变当前图形。
- 每个星座包含 `8–14` 个基础星点、独立连线和最多七个文章锚点。全部暗星与连线始终存在；文章依次绑定锚点并点亮星星，同时逐段增强与已点亮星点关联的连线。没有文章时仍显示完整暗态星座，不得留下空白区域。
- 每次加载或换批时，文章星点与标题按约 `110–130ms` 的间隔依次点亮；点击星点进入文章详情。文章标题在桌面端提高到约 `0.76rem`，声纳分类标题提高到约 `0.84rem`，移动端使用独立字号和标签方向避免重合。
- 精选模式提供“进入竞赛中心”，分类模式提供“进入该竞赛”。空状态与读取失败叠加在暗态星座上方，不改变章节高度。
- `prefers-reduced-motion` 下停止扫描、中心脉冲、余辉和逐星点亮，只保留静态声纳、方位线、分类节点、暗态星座及完整文章信息。

## 连续场景架构

首页不是六张相邻的全屏海报，而是一台持续向深处移动的观察镜头。章节负责组织信息，海水、光线和生物环境负责维持连续空间。实现分为四个始终协作的视觉层：

1. **海洋环境层**：固定在视口背后，根据当前水深在星空蓝、浅海蓝、中层青绿和深渊黑之间交叉渐变。
2. **生物光粒子层**：使用单个 Canvas 贯穿首页。星尘、水雾、气泡、浮游生物和少量水母轮廓随深度变化，但不会在章节边界重新生成。
3. **场景插画层**：鲸鱼、海面、海草、科研舱和海底星图采用遮罩、透明度与轻微视差衔接，不显示完整图片的硬边缘。
4. **内容章节层**：每章严格占据一个动态视口，承载标题、正文和交互内容，并按连续下潜进度完成交叉显隐。

全站唯一的强视觉动作仍然是“随鲸下潜”。粒子、渐变和章节动画都服务于这次运动，不能各自成为独立的装饰表演。

## 视口与吸附

- 首页导航覆盖在场景上方，不参与文档流；每个章节严格占据一个完整的动态视口 `100dvh`。
- 用户滚动期间不拦截滚轮或触摸，画面自然经过章节边界，避免浏览器强制吸附产生突兀的二次位移。
- 当用户停止滚动且距离章节边界很近时，才进行一次短距离、慢速的弱停靠；停在转场中部时允许保持当前位置。停靠目标以章节实际 `offsetTop` 计算，不以视口倍数猜测。
- 桌面端与移动端使用同一套章节坐标。桌面端仅在距边界约 `8vh` 内弱停靠，移动端进一步收窄到约 `5vh`，兼容地址栏变化和短屏设备。
- 首页只展示有限数量的精选内容。动态数据不得撑高章节，完整内容通过内页继续浏览。
- 章节使用统一的顶部安全区、底部安全区和稳定网格，文字或空状态不能改变章节高度。

章节起点统一为 `0、100dvh、200dvh……`。导航的视觉高度只影响内容的安全内边距，不再通过 `scroll-padding-top`、`scroll-margin-top` 或章节减高参与滚动坐标计算。

## 转场语言

所有章节使用同一种运动语法：离场内容向上漂移并轻微失焦，新章节从下方或远处由模糊变清晰。动画不再等待章节被判定为“激活”后逐项播放，而是用约 `110–140ms` 的轻量跟随平滑滚动采样，从而支持反向滚动并避免动画滞后。

背景和内容不再只根据“当前章节”离散切换，而是根据连续的下潜进度插值：上一章逐渐淡出、下一章逐渐淡入，Canvas 粒子的颜色、密度和速度同步变化。用户可以在两个章节之间短暂停留并看到完整的转场画面。

章节之间的环境变化发生在滚动过程中，而不是吸附完成后突然切换：

- **海面 → 知识潮汐**：海平线上移，月光倒影被拉长，鲸鱼水花转化为气泡，气泡继续下沉并成为发光知识节点。
- **知识潮汐 → 竞赛航线**：知识节点被洋流拉成路径，最终形成竞赛航线和声呐圆环。
- **竞赛航线 → 时间回声**：声呐波纹继续扩散，逐渐变成时间刻度和历史信号。
- **时间回声 → 同行灯火**：冷色信号收束为科研舱的暖色观察窗和舱内灯光。
- **同行灯火 → 海底星图**：舱内金色灯光散开，成为海底星图与荣誉坐标。

第一、二章之间是最重要的转场。两张插画在约 `15%–20%` 的视口范围内重叠，海面反射、折射光束、水花和气泡共同遮蔽图像边界，形成穿过海面的感觉。

## 生物光系统

粒子层按水深改变形态和密度：

- `00m`：稀疏金色星点和水雾，运动轻微。
- `80m`：蓝白气泡与发光浮游生物，密度最高。
- `300m`：青绿色微光沿洋流移动，偶尔出现半透明水母轮廓。
- `900m`：粒子变慢并减少，主要表现远处信号与冷白生物光。
- `1800m`：环境保持克制，科研舱附近出现少量暖金尘埃。
- `4000m`：粒子极度稀疏，并逐渐转化为金色荣誉星点。

Canvas 必须限制设备像素比和粒子数量，页面不可见时暂停动画；移动端降低密度并隐藏水母细节。`prefers-reduced-motion` 下停止漂移动画，只保留静态环境光点。

## 全屏模式

首页提供原生 Fullscreen API 全屏入口。全屏后隐藏站点级导航和页脚，仅保留水深导航、全屏退出按钮和章节内容；按 `Esc` 或再次点击按钮退出。进入与退出时记录“当前章节 + 章节内进度”，在视口尺寸变化后恢复同一相对位置，而不是跳回章节起点。移动浏览器不支持原生全屏时，降级为隐藏站点壳层的沉浸模式，不劫持系统滚动。

## 界面边界

- 首页使用大画面、章节转场和有限的环境动效。
- 列表页保持内容丰富，但采用清晰的水深标签、轻量背景和可扫描布局。
- 文章详情优先保证阅读、目录、附件、代码和公式体验。
- 工作台与管理后台采用安静的科研控制台风格，不复制首页的沉浸动画。
- 移动端保持原生滚动机制，只在停止滚动且接近章节边界时进行弱停靠，不进行滚轮或触摸事件劫持。
- 所有动画尊重 `prefers-reduced-motion`，键盘焦点必须可见。
