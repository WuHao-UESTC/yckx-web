# 视觉概念草案：鲸落星海

## 设计命题

网站面向英才实验学院在校生、准备加入科协的学生和对外访客。首页的任务不是平铺所有功能，而是让访客跟随一只座头鲸，从星空与海面逐步下潜，在探索过程中进入科协的知识、竞赛、记忆、日常和精神世界。

滚动是一次下潜。座头鲸只在关键转场出现，鲸歌、气泡、光束和远处轮廓在其他章节延续它的存在，避免把鲸鱼变成重复出现的装饰物。

## 视觉语言

### 色彩

- 星空蓝 `#061A3A`：海面、夜空和品牌背景。
- 海洋蓝 `#0B5B8E`：浅海、水体和主要交互。
- 深渊蓝 `#031018`：深海章节与页脚。
- 月光白 `#F5FBFF`：主文字、鲸鱼高光和水面反射。
- 星芒金 `#F2C66D`：星辰、荣誉与关键节点。
- 海草绿 `#0E4B3B`：浅海生态和辅助状态。

金色只出现在荣誉、星辰和少量重点操作中。蓝色不单独承担全部层次，白色、墨绿和金色共同维持综合色彩。

### 字体

- 品牌标题：现代中文衬线字体，承担梦幻与叙事感。
- 正文与导航：清晰的中文无衬线字体，保证长文和操作效率。
- 水深、年份和坐标：等宽字体，建立科学观测感。

### 标志性元素

整站唯一的强视觉动作是“鲸鱼带领页面下潜”。右侧水深标尺承担章节导航和当前位置提示，属于信息结构，不是装饰。

## 首页章节

1. `00m 海面`：鲸鱼跃出星空下的海面，展示协会全称和“随鲸下潜”入口。
2. `80m 知识潮汐`：海草森林与生物荧光节点组成知识网络，进入知识库分类和精选文章。
3. `300m 竞赛航线`：声呐圆环和洋流路径表现竞赛方向、经验与成果。
4. `900m 时间回声`：新闻作为最新信号，大事记沿水深形成时间线。
5. `1800m 同行灯火`：深海科研舱、照片舷窗、成员与便签形成温暖的科协日常。
6. `4000m 海底星图`：鲸歌点亮金色荣誉节点，以精神理念和竞赛成果完成星空与海洋的呼应。

### 900m 时间回声交互

- 章节标题位于页面左上方，字号低于其他叙事章节；大事记回声移至标题右侧的页面上部，为下方科协档案夹和观测台留出完整工作区。
- 初始状态展示合上的深绿色布面“科协档案夹”；点击后由夹套中抽出单张编号档案纸，新闻按发布时间从新到旧逐页显示。档案纸包含标题、撰稿人、发布时间和正文摘要，右侧页签显示新闻顺序。
- 档案夹关闭时，右侧展示一体化的“发表信号观测台”。观测台比档案夹略高并与其底部对齐，二者拉开明确间距；上方依次显示已发布文章、分类、成员、浏览量以及知识库、竞赛、新闻、活动、专栏和日常各板块的分类数与文章数，下方使用扩大后的网格折线图展示文章发表趋势。
- 发表趋势提供周、月、年分段选择。周视图展示最近七天的每日发布量，月视图展示最近三十天的每日发布量，年视图展示最近十二个月的每月发布量；首页默认使用月视图。折线使用珊瑚红，当前游标使用星芒金，避免与深海青背景混合。
- 档案夹展开后转变为居中的大型“档案阅览台”，占据标题下方绝大部分可用空间并允许遮挡大事记。阅览台由左侧编号与元数据栏、中央新闻档案纸、右侧新闻目录组成；新闻标题和“阅读完整新闻稿”进入新闻详情，“进入新闻与大事记”进入统一档案入口，同时保留目录选择、前后翻页与合上操作。
- 右上角约 `44vw`、最多 `680px` 的裁切椭圆回声纹路同时承担大事记时间轴。椭圆圆心位于页面右上侧，弧线从上方向右侧展开；首页最多读取十二条大事记，按照 `4 / 3 / 3 / 2` 的容量由最外圈向内圈填充，每圈节点沿弧线排列并错开起始角度，避免形成径向队列。
- 回声圈使用冷白、青绿、海蓝、淡紫与少量星芒金组成的 SVG 虚线流光。节点默认只显示时间，悬停或键盘聚焦时沿圆环切线产生受限粒子，并更新共用的“回声读数”区域；点击节点可以固定当前读数。
- “回声读数”位于回声区域下沿内侧、观测台上方并避开右侧水深导航，使用烟熏墨绿底色、黄铜边框、珊瑚红日期与暖白标题，与深海背景形成明确分离；当前节点通过黄铜虚线引线关联读数区域。
- 移动端隐藏占地较大的椭圆图形，保留原生横向浏览的节点序列和共享读数，不让档案夹、标题和时间轴相互遮挡。
- `prefers-reduced-motion` 下停止流光、抽取和粒子动画，保留静态回声、节点高亮、档案内容与完整操作。

### 900m 统计口径

- 首页观测台仅统计状态为 `PUBLISHED` 的文章，发布时间使用 `publishedAt`，日期边界使用 `Asia/Shanghai` 时区。
- 板块分类数统计已经创建的全部分类；板块文章数统计这些分类下的已发布文章。全站文章总数包含未归类的已发布文章。
- 趋势数据在服务端一次生成并随首页内容返回，前端切换周、月、年时不再请求数据库；没有文章的日期必须补零，不能省略或制造虚假趋势。

### 80m 知识潮汐交互

知识库分类不再使用固定圆形入口，而是组成一片可拖拽的线描水母知识网络。水母只保留伞盖轮廓和少量触须，分类标题与文章数量独立位于形象下方并随节点移动，不把文字挤入生物内部。所有节点保持相近尺度，避免暗示不存在的分类层级。

- 图谱没有可见外框、内圈或中心枢纽，仅使用不可见安全边界和碰撞力把节点留在可操作海域内。
- 分类之间使用稳定伪随机拓扑：先保证全部节点连通，再补充少量跨节点连接；每个节点通常维持两至三条连接，最多四条。连接关系不因刷新或分类顺序变化而随机跳变。
- 连接线采用低透明度蓝白实线。悬停或聚焦时轻微强调当前节点及其邻接关系；拖拽时仅高亮周围连接线和直接相邻节点，并通过弹簧力轻微牵动邻居。拖拽使用冷白青高亮，点击选中使用星芒金高亮。
- 空闲状态下，分类水母从不规则散点位置出发，受微弱洋流、连接弹力和避让力影响缓慢漂移，不形成圆环或整齐队列。指针悬停或键盘聚焦时，当前水母只减速而不改变图谱结构。
- 水母伞盖、触须和微光使用同一呼吸周期：伞盖收缩时光晕略亮并收束，舒展时光晕变淡并扩散；各节点使用错开的动画相位，避免同步律动。
- 拖拽只改变节点位置和连接关系的空间表现，不直接进入分类。拖拽结束后，未选中的水母重新加入洋流。
- 点击分类后，仅固定当前水母的位置并继续伞体律动；标题、线描轮廓和相连实线使用星芒金高亮，其他节点保持低速漂移。
- 文章列表从水母周围可用空间最大的方向出现。桌面端依次尝试右、左、右下和左下位置，并把列表区域作为其他节点的临时碰撞障碍；移动端使用图谱下方预留的潮汐托盘，列表不得覆盖当前水母。
- 列表固定预留五行高度，每条文章以约 `110–140ms` 的间隔逐条显现。每批最多五篇；超过五篇时提供“换一批”，按稳定游标顺序切换，避免随机重复。
- 点击文章进入文章详情，点击“进入分类”才进入分类页。再次点击已选水母、点击空白海域或按 `Esc` 关闭列表并解除定锚。
- 章节底部的精选文章条仅在图谱空闲时显示；分类被选中后淡出，避免与上下文文章列表争夺注意力。
- 图谱不接管滚轮缩放，不劫持首页自然下潜。触摸端只在明确拖拽节点后捕获指针。
- `prefers-reduced-motion` 下停止漂流、律动和逐条显现，保留静态节点、选中高亮和完整列表。

### 300m 竞赛航线交互

竞赛分类不再使用纵向列表，而是作为黄铜深海水听站中的回波目标分布在圆形扫描区域内。冷色海水负责环境纵深，黄铜、铜红、琥珀和暖白负责声纳仪器与信号反馈，避免声纳再次融入青蓝背景。桌面端由左侧声纳承担分类选择，右侧上方使用与其他章节一致的大标题，右侧下方展示稳定映射的星座信号图；移动端依次排列标题、声纳、文章星图与编号信号清单。整章的主要动作链为“扫描、命中、锁定、传输、点亮”，不叠加无关的科幻仪表装饰。

- 声纳最多展示七个竞赛分类。分类坐标由稳定伪随机槽位生成，刷新和分类排序变化不会导致位置跳动；桌面端与移动端分别使用适配字号的安全间距，标题不得重合。
- 声纳圆周显示克制的方位刻度与 `000° / 090° / 180° / 270°` 标记，中心发射器周期性向外扩散琥珀色低频探测波。圆环与刻度使用暗黄铜，扫描主线使用暖白，拖尾由铜红渐变至琥珀；少量无文字、不可点击的暖色杂波与矿物微粒维持深海回波密度，但不得与真实分类混淆。
- 扫描指针以十秒为周期匀速旋转，由暖白扫描线、约 `25–35°` 的铜红扇形拖尾和两道快速消散的黄铜弧形残影组成。扫描经过分类节点时，节点短暂出现橙金描边、扩散环和光晕；扫描反馈不改变当前选择。
- 点击分类只锁定该竞赛航线并切换文章信号，不直接导航。选中后从声纳中心向目标绘制细金色方位线，目标持续显示金色状态与 `AZ 方位角 · LOCKED` 读数；再次点击、按 `Esc` 或使用关闭按钮返回精选模式。
- 未选择分类时，文章区域查询已发布且标记为精选的竞赛文章；选中后查询该分类下的已发布文章。两种模式每批最多七篇，超过七篇时提供“换一批”，并按稳定游标循环切换。
- 星图预设白羊、金牛、双子、巨蟹、狮子、处女、天秤、天蝎、射手、摩羯、水瓶和双鱼十二种抽象轮廓。分类模式根据分类 `slug` 固定映射星座；精选模式根据批次游标稳定切换，组件重渲染不得改变当前图形。
- 每个星座包含 `8–14` 个基础星点、独立连线和最多七个文章锚点。全部暗星与连线始终存在；文章依次绑定锚点并点亮星星，同时逐段增强与已点亮星点关联的连线。没有文章时仍显示完整暗态星座，不得留下空白区域。
- 桌面端将星座压缩到中央观测带，文章标题稳定分配到左右两条隐形标注轨道，每侧最多四条。标题按照星点横坐标分侧、纵坐标排序，并以最小安全间距进行碰撞避让；星点通过折线引线连接标题，完整标题不得直接堆叠在星座内部。
- 每次加载或换批时，文章星点、引线与标题按约 `110–130ms` 的间隔依次点亮。文章标题提高到约 `0.88rem`，分类与日期提高到约 `0.56rem`，星图标题提高到约 `1.24rem`，英文状态副标题提高到约 `0.62rem`。
- 移动端恢复星座的完整宽度，在文章锚点旁显示 `1–7` 编号，并在星图下方使用双列编号信号清单展示文章标题；不得把七个长标题继续压在狭窄星图周围。
- `300m / 竞赛航线` 保留在章节标识位置，并与 `80m / 知识潮汐` 使用相同的字号与字体规则；主标题继续使用“把未知拆成问题，把问题变成可以抵达的坐标”。桌面端在声纳与星图之间保留一条低亮铜色传输轨迹，选中分类后暖白信号沿轨迹进入星图，再触发文章星点点亮。
- 精选模式提供“进入竞赛中心”，分类模式提供“进入该竞赛”。空状态与读取失败叠加在暗态星座上方，不改变章节高度。
- `prefers-reduced-motion` 下停止扫描、中心脉冲、余辉和逐星点亮，只保留静态声纳、方位线、分类节点、暗态星座及完整文章信息。

### 1800m 同行灯火交互

同行灯火不再使用把照片、成员和留言包裹在一起的科研舱控制台。整章改为由上至下连续展开的三个场景：标题与鲸形照片墙、纸质留言通栏、成员鱼群。三者共享深海科研站附近的克制环境光，但只有鲸形照片拼贴承担强视觉焦点。

- 章节上部使用左右布局。左侧保留 `1800m / 同行灯火`、主标题和简短叙事，右侧由固定一百一十六个照片槽位拼成一只破水跃起的座头鲸；鲸头抬向左上方，躯干向右下方收束，两侧长胸鳍错位展开，尾鳍位于最低处，使照片墙具有清晰的出水动势。鲸头保留嘴线和眼部留白，强化座头鲸的识别度。
- 照片使用 `24 × 15` 的高密度坐标网格，但只渲染与座头鲸蒙版有实质交叠的一百一十六个槽位，蒙版负责彻底裁除每个边缘槽位位于轮廓外的部分，不再创建完全处于轮廓外的照片元素。每个槽位保持独立的图片裁切、键盘焦点和点击区域；悬停或聚焦时当前照片轻微浮起并放大，点击打开当前批次的灯箱查看器。
- 每批最多一百一十六张照片，并按服务端顺序稳定循环。超过一百一十六张时显示“换一批”，不足时只在鲸鱼内部保留带有低亮纹理的空槽，不拉伸现有照片填满轮廓。灯箱支持关闭、前后切换与键盘方向键。
- 章节中部固定预留五张便签的位置。便签使用麦秆黄、浅杏、旧桃粉和灰绿色等暖色纸张，叠加低对比度纤维纹理、轻微折痕与边缘阴影；五个位置采用稳定的偏移和旋转，不在每次渲染时随机变化。
- 每批最多五条留言，超过五条时提供稳定循环的“换一批”。不足时保留空白纸张，首个空位可显示等待状态；正文限制行数，作者作为纸张下沿的小字签名。完整发布与删除功能继续通过 `/routine` 提供。
- 章节底部为无卡片外框的成员鱼群水层。成员鱼使用与 `80m` 水母一致的半透明线描、生物光青色轮廓、低亮光晕和错相呼吸节奏，不使用写实鱼类图片或通用图标。
- 成员根据稳定标识分配到三条泳道，并交替从左右两侧向对侧游动；姓名通过短线跟随在鱼尾后方，鱼体翻转时文字始终保持正向。同屏数量通过持续时间和负延迟控制，成员顺序不得在组件重渲染时跳变。
- 悬停或键盘聚焦成员鱼时，仅当前鱼暂停并转为暖金高亮，鱼群上方共用的成员读数区显示头像或首字、姓名、职务、简介与公开文章数；点击鱼直接进入对应成员主页。
- 桌面端仍将三部分完整收纳在单个 `100dvh` 章节内。移动端保持标题与鲸形照片墙的并置关系，五张便签改为两排紧凑散落，鱼群减少为两条可视泳道，任何内容变化不得撑高章节。
- `prefers-reduced-motion` 下停止鱼群游动、照片浮起和纸张动态过渡，成员鱼改为静态分散排列；照片查看、批次切换、成员信息和全部导航仍然可用。

## 二级路由视觉体系

除首页以外的页面不再共用浅色背景、棕色强调色和通用卡片网格。二级路由只继承对应首页章节的海深、配色、材质、文案和一个代表性元素，不复制首页的全屏布局、Canvas 动画或章节交互。列表、详情、表单和管理界面可以按照实际任务自由组织。

- `/knowledge-base`、`/search` 与 `/tags` 继承 `80m / 知识潮汐`。使用深海青、冷白和生物光青，分类以潮汐节点表达，二级页面标题带使用三角形构成的稳定矢量标记，文章以连续信号行和洋流轨迹组织，不再使用整齐卡片矩阵。
- `/competition` 继承 `300m / 竞赛航线`。使用黄铜、铜红、暖白和深海青，分类以声纳目标、方位读数或航线标记表达，文章列表表现为已经捕获的竞赛信号。
- `/archive` 以及兼容入口 `/news`、`/events` 继承 `900m / 时间回声`。新闻使用档案纸和编号，事件使用年份刻度与回声时间轴，专栏使用档案夹书脊或索引签。
- `/routine` 与 `/friends` 继承 `1800m / 同行灯火`。照片、纸质便签、暖金灯光和线描生物光鱼是主要材料；成员主页表现为同行者观测记录，而不是居中的个人信息卡片。
- `/dashboard` 继承 `1800m` 的舱内工作层。使用烟熏墨绿、暖金、冷白和低亮青色，保持表格、编辑器、文件管理与表单的高密度和稳定性，不复制首页的照片鲸鱼或鱼群动画。
- `/admin` 继承 `4000m / 海底星图`。使用深渊黑、星芒金、冷白和少量灰蓝，以站点读数、坐标轨道、管理表格和变更日志为主，不制作营销式仪表盘。
- `/login` 与 `/register` 继承 `00m / 海面`，以星空蓝、月光白和少量金色构成简洁的下潜入口；认证表单本身保持直接、清晰和无装饰干扰。

二级路由统一使用紧凑的领域标题带：显示海深、章节名、当前页面标题和必要说明。领域标题带不是首页 Hero，不占据完整首屏，首屏必须同时露出真实内容或可执行操作。首页文案与内页文案发生冲突时，以首页为准，并由共享文案常量提供以下句子：

- 知识潮汐：知识不是孤岛，它在分享中形成洋流。
- 竞赛航线：把未知拆成问题，把问题变成可以抵达的坐标。
- 时间回声：每一次发生，都在深处留下回声。
- 同行灯火：越向深处，同行的灯光越显得珍贵。
- 海底星图：星光沉入海底，成为我们共同抵达过的坐标。

公共文章详情继续优先保证正文、目录、附件、代码、公式和评论的可读性。页面使用领域环境背景包围无卡片外框的浅色阅读带：知识文章偏冷白，竞赛文章带黄铜刻度，新闻与事件文章带档案编号和日期轴。正文阅读带与上方标题容器等宽；宽屏桌面的大纲固定悬浮在视口最右侧，随滚动持续可见且不参与正文排版，侧方空间不足时切换为正文顶部的可折叠目录。页面不因主题装饰缩窄正文或遮挡目录。

正文排版提供三套可选风格：默认风格使用舒展的站点阅读节奏；技术文档风格强化无衬线层级、代码、表格和提示信息；论文阅读风格强化中文衬线正文、引用、公式和长段落。三种风格共享同一 Markdown 语义与功能组件，不复制渲染器。

内页动效低于首页：知识节点仅缓慢呼吸，竞赛声纳只保留低频扫描，档案回声只在交互时出现，工作台和后台的主要操作区保持静止。`prefers-reduced-motion` 下停止所有漂移、扫描和脉冲，但保留主题颜色、层级和状态反馈。

## 连续场景架构

首页不是六张相邻的全屏海报，而是一台持续向深处移动的观察镜头。章节负责组织信息，海水、光线和生物环境负责维持连续空间。实现分为四个始终协作的视觉层：

1. **海洋环境层**：固定在视口背后，根据当前水深在星空蓝、浅海蓝、中层青绿和深渊黑之间交叉渐变。
2. **生物光粒子层**：使用单个 Canvas 贯穿首页。星尘、水雾、气泡、浮游生物和少量水母轮廓随深度变化，但不会在章节边界重新生成。
3. **场景插画层**：鲸鱼、海面、海草、科研舱和海底星图采用遮罩、透明度与轻微视差衔接，不显示完整图片的硬边缘。
4. **内容章节层**：每章严格占据一个动态视口，承载标题、正文和交互内容，并按连续下潜进度完成交叉显隐。

全站唯一的强视觉动作仍然是“随鲸下潜”。粒子、渐变和章节动画都服务于这次运动，不能各自成为独立的装饰表演。

## 视口与吸附

- 首页导航覆盖在场景上方，不参与文档流；每个章节严格占据一个完整的动态视口 `100dvh`。
- 用户滚动期间不拦截滚轮或触摸，画面自然经过章节边界，避免浏览器强制吸附产生突兀的二次位移。
- 当用户停止滚动且距离章节边界很近时，才进行一次短距离、慢速的弱停靠；停在转场中部时允许保持当前位置。停靠目标以章节实际 `offsetTop` 计算，不以视口倍数猜测。
- 桌面端与移动端使用同一套章节坐标。桌面端仅在距边界约 `8vh` 内弱停靠，移动端进一步收窄到约 `5vh`，兼容地址栏变化和短屏设备。
- 首页只展示有限数量的精选内容。动态数据不得撑高章节，完整内容通过内页继续浏览。
- 章节使用统一的顶部安全区、底部安全区和稳定网格，文字或空状态不能改变章节高度。

章节起点统一为 `0、100dvh、200dvh……`。导航的视觉高度只影响内容的安全内边距，不再通过 `scroll-padding-top`、`scroll-margin-top` 或章节减高参与滚动坐标计算。

## 转场语言

所有章节使用同一种运动语法：离场内容向上漂移并轻微失焦，新章节从下方或远处由模糊变清晰。动画不再等待章节被判定为“激活”后逐项播放，而是用约 `110–140ms` 的轻量跟随平滑滚动采样，从而支持反向滚动并避免动画滞后。

背景和内容不再只根据“当前章节”离散切换，而是根据连续的下潜进度插值：上一章逐渐淡出、下一章逐渐淡入，Canvas 粒子的颜色、密度和速度同步变化。用户可以在两个章节之间短暂停留并看到完整的转场画面。

章节之间的环境变化发生在滚动过程中，而不是吸附完成后突然切换：

- **海面 → 知识潮汐**：海平线上移，月光倒影被拉长，鲸鱼水花转化为气泡，气泡继续下沉并成为发光知识节点。
- **知识潮汐 → 竞赛航线**：知识节点被洋流拉成路径，最终形成竞赛航线和声呐圆环。
- **竞赛航线 → 时间回声**：声呐波纹继续扩散，逐渐变成时间刻度和历史信号。
- **时间回声 → 同行灯火**：冷色信号收束为科研舱的暖色观察窗和舱内灯光。
- **同行灯火 → 海底星图**：舱内金色灯光散开，成为海底星图与荣誉坐标。

第一、二章之间是最重要的转场。两张插画在约 `15%–20%` 的视口范围内重叠，海面反射、折射光束、水花和气泡共同遮蔽图像边界，形成穿过海面的感觉。

## 生物光系统

粒子层按水深改变形态和密度：

- `00m`：稀疏金色星点和水雾，运动轻微。
- `80m`：蓝白气泡与发光浮游生物，密度最高。
- `300m`：青绿色微光沿洋流移动，偶尔出现半透明水母轮廓。
- `900m`：粒子变慢并减少，主要表现远处信号与冷白生物光。
- `1800m`：环境保持克制，科研舱附近出现少量暖金尘埃。
- `4000m`：粒子极度稀疏，并逐渐转化为金色荣誉星点。

Canvas 必须限制设备像素比和粒子数量，页面不可见时暂停动画；移动端降低密度并隐藏水母细节。`prefers-reduced-motion` 下停止漂移动画，只保留静态环境光点。

## 全屏模式

首页提供原生 Fullscreen API 全屏入口。全屏后隐藏站点级导航和页脚，仅保留水深导航、全屏退出按钮和章节内容；按 `Esc` 或再次点击按钮退出。进入与退出时记录“当前章节 + 章节内进度”，在视口尺寸变化后恢复同一相对位置，而不是跳回章节起点。移动浏览器不支持原生全屏时，降级为隐藏站点壳层的沉浸模式，不劫持系统滚动。

## 界面边界

- 首页使用大画面、章节转场和有限的环境动效。
- 列表页保持内容丰富，但采用清晰的水深标签、轻量背景和可扫描布局。
- 文章详情优先保证阅读、目录、附件、代码和公式体验。
- 工作台与管理后台采用安静的科研控制台风格，不复制首页的沉浸动画。
- 移动端保持原生滚动机制，只在停止滚动且接近章节边界时进行弱停靠，不进行滚轮或触摸事件劫持。
- 所有动画尊重 `prefers-reduced-motion`，键盘焦点必须可见。
