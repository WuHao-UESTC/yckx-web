# 视觉概念草案：鲸落星海

## 设计命题

网站面向英才实验学院在校生、准备加入科协的学生和对外访客。首页的任务不是平铺所有功能，而是让访客跟随一只座头鲸，从星空与海面逐步下潜，在探索过程中进入科协的知识、竞赛、记忆、日常和精神世界。

滚动是一次下潜。座头鲸只在关键转场出现，鲸歌、气泡、光束和远处轮廓在其他章节延续它的存在，避免把鲸鱼变成重复出现的装饰物。

## 视觉语言

### 色彩

- 星空蓝 `#061A3A`：海面、夜空和品牌背景。
- 海洋蓝 `#0B5B8E`：浅海、水体和主要交互。
- 深渊蓝 `#031018`：深海章节与页脚。
- 月光白 `#F5FBFF`：主文字、鲸鱼高光和水面反射。
- 星芒金 `#F2C66D`：星辰、荣誉与关键节点。
- 海草绿 `#0E4B3B`：浅海生态和辅助状态。

金色只出现在荣誉、星辰和少量重点操作中。蓝色不单独承担全部层次，白色、墨绿和金色共同维持综合色彩。

### 字体

- 品牌标题：现代中文衬线字体，承担梦幻与叙事感。
- 正文与导航：清晰的中文无衬线字体，保证长文和操作效率。
- 水深、年份和坐标：等宽字体，建立科学观测感。

### 标志性元素

整站唯一的强视觉动作是“鲸鱼带领页面下潜”。右侧水深标尺承担章节导航和当前位置提示，属于信息结构，不是装饰。

## 首页章节

1. `00m 海面`：鲸鱼跃出星空下的海面，展示协会全称和“随鲸下潜”入口。
2. `80m 知识潮汐`：海草森林与生物荧光节点组成知识网络，进入知识库分类和精选文章。
3. `300m 竞赛航线`：声呐圆环和洋流路径表现竞赛方向、经验与成果。
4. `900m 时间回声`：新闻作为最新信号，大事记沿水深形成时间线。
5. `1800m 同行灯火`：深海科研舱、照片舷窗、成员与便签形成温暖的科协日常。
6. `4000m 海底星图`：鲸歌点亮金色荣誉节点，以精神理念和竞赛成果完成星空与海洋的呼应。

## 连续场景架构

首页不是六张相邻的全屏海报，而是一台持续向深处移动的观察镜头。章节负责组织信息，海水、光线和生物环境负责维持连续空间。实现分为四个始终协作的视觉层：

1. **海洋环境层**：固定在视口背后，根据当前水深在星空蓝、浅海蓝、中层青绿和深渊黑之间交叉渐变。
2. **生物光粒子层**：使用单个 Canvas 贯穿首页。星尘、水雾、气泡、浮游生物和少量水母轮廓随深度变化，但不会在章节边界重新生成。
3. **场景插画层**：鲸鱼、海面、海草、科研舱和海底星图采用遮罩、透明度与轻微视差衔接，不显示完整图片的硬边缘。
4. **内容章节层**：每章严格占据一个可用视口，承载标题、正文和交互内容，并执行吸附与分阶段入场。

全站唯一的强视觉动作仍然是“随鲸下潜”。粒子、渐变和章节动画都服务于这次运动，不能各自成为独立的装饰表演。

## 视口与吸附

- 首页导航覆盖在场景上方；每个章节高度等于动态视口高度减去导航高度。
- 桌面端采用严格的纵向吸附，每次滚动稳定落在一个完整章节上。
- 移动端保留逐章吸附，但使用较柔和的吸附强度，兼容浏览器地址栏高度变化和短屏设备。
- 首页只展示有限数量的精选内容。动态数据不得撑高章节，完整内容通过内页继续浏览。
- 章节使用统一的顶部安全区、底部安全区和稳定网格，文字或空状态不能改变章节高度。

## 转场语言

所有章节使用同一种运动语法：离场内容向上漂移并轻微失焦，新章节从下方或远处由模糊变清晰；水深标签、图标、标题、正文、主操作和数据视图依次出现。入场间隔控制在约 `60–100ms`，退出速度略快，并支持反向滚动。

章节之间的环境变化发生在滚动过程中，而不是吸附完成后突然切换：

- **海面 → 知识潮汐**：海平线上移，月光倒影被拉长，鲸鱼水花转化为气泡，气泡继续下沉并成为发光知识节点。
- **知识潮汐 → 竞赛航线**：知识节点被洋流拉成路径，最终形成竞赛航线和声呐圆环。
- **竞赛航线 → 时间回声**：声呐波纹继续扩散，逐渐变成时间刻度和历史信号。
- **时间回声 → 同行灯火**：冷色信号收束为科研舱的暖色观察窗和舱内灯光。
- **同行灯火 → 海底星图**：舱内金色灯光散开，成为海底星图与荣誉坐标。

第一、二章之间是最重要的转场。两张插画在约 `15%–20%` 的视口范围内重叠，海面反射、折射光束、水花和气泡共同遮蔽图像边界，形成穿过海面的感觉。

## 生物光系统

粒子层按水深改变形态和密度：

- `00m`：稀疏金色星点和水雾，运动轻微。
- `80m`：蓝白气泡与发光浮游生物，密度最高。
- `300m`：青绿色微光沿洋流移动，偶尔出现半透明水母轮廓。
- `900m`：粒子变慢并减少，主要表现远处信号与冷白生物光。
- `1800m`：环境保持克制，科研舱附近出现少量暖金尘埃。
- `4000m`：粒子极度稀疏，并逐渐转化为金色荣誉星点。

Canvas 必须限制设备像素比和粒子数量，页面不可见时暂停动画；移动端降低密度并隐藏水母细节。`prefers-reduced-motion` 下停止漂移动画，只保留静态环境光点。

## 界面边界

- 首页使用大画面、章节转场和有限的环境动效。
- 列表页保持内容丰富，但采用清晰的水深标签、轻量背景和可扫描布局。
- 文章详情优先保证阅读、目录、附件、代码和公式体验。
- 工作台与管理后台采用安静的科研控制台风格，不复制首页的沉浸动画。
- 移动端保持原生滚动机制，只使用 CSS 吸附，不进行滚轮或触摸事件劫持。
- 所有动画尊重 `prefers-reduced-motion`，键盘焦点必须可见。
