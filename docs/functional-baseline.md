# 功能基线

本文档记录工程重构前必须保留的功能和行为。除非在变更记录中明确说明，否则重构后的页面、接口和数据迁移不得删除这些能力。

### 首页 80m 知识潮汐

- 分类图谱必须由分类间的稳定稀疏连接组成，不得依赖单一中心节点；全部分类保持连通，每个节点最多四条连接。
- 水母节点可以拖拽，拖拽期间与其直接相连的实线和相邻节点必须高亮，连接线必须实时跟随位置变化。
- 空闲节点保持缓慢、不规则的自由移动；悬停或聚焦只让当前节点减速，选中节点固定位置但保留水母律动和呼吸微光。
- 图谱不得显示用于框定活动范围的边框、内圈或容器卡片；安全边界仍需阻止节点离开可操作区域。
- 点击分类只进行金色选中并打开附近文章列表，不直接导航；文章列表不得遮挡选中节点，每批最多五篇并保留“换一批”和“进入分类”。

### 首页 300m 竞赛航线

- 声纳区域最多展示七个互不重叠、位置稳定的竞赛分类，点击分类只切换探测模式，不直接导航。
- 声纳必须以黄铜、铜红、琥珀和暖白为主要信号色，与冷色海水背景形成明确对比；扫描包含可辨认的多层拖尾、方位刻度和中心脉冲，经过目标时显示短暂橙金边缘，选中目标保持暖金状态、中心方位线和锁定读数。
- 未选中分类时只展示已发布的精选竞赛文章；选中后只展示该分类下的已发布文章。
- 文章星图必须从十二种预设星座中稳定选择。星座暗星和连线始终展示，文章按最多七个锚点依次点亮；没有文章时不得隐藏星座骨架。
- 桌面端文章标题必须通过左右标注轨道和引线关联星点，每侧最多四条并执行纵向碰撞避让；移动端必须改用编号星点和双列文章信号清单。
- `300m / 竞赛航线` 必须保留为章节标识，并与 `80m / 知识潮汐` 使用相同字号；不得替换原有主标题。星图标题、副标题和文章标题不得继续使用当前的小字号。
- 桌面端选中分类后，声纳与星图之间必须出现暖色信号传输反馈；该装饰不可阻挡点击，也不可改变章节布局尺寸。
- 每批最多七篇并保留稳定游标“换一批”；分类模式必须提供“进入该竞赛”，默认模式提供竞赛中心入口。
- 加载、错误、空状态和文章批次变化不得撑高 300m 章节或改变首页章节坐标。

### 首页 900m 时间回声

- 标题置于章节上方并适当缩小，右下角保留提亮后的回声纹路作为大事记时间轴。
- 大事记按时间从最外圈向内圈填充，同一圈必须沿弧线排列多个节点而非径向排列；首页最多读取最近十二条，后台列表按时间倒序维护。
- 回声圈必须保留流光效果；悬停或聚焦节点时更新共用的时间、标题与描述读数，鼠标悬停可产生受限粒子效果，点击可固定选择。
- 新闻使用合上与展开的“科协档案夹”展示，初次进入保持合上状态，展开后以单张档案纸从新到旧逐页浏览。
- 每页新闻包含可进入完整稿件的标题、撰稿人、发布时间和正文摘要，并提供页签选择、翻页、合上档案夹和进入科协新闻的操作。
- 空新闻和空大事记必须提供明确状态；移动端不得出现标题、日志和时间轴重叠。
- 减少动态效果时必须停止流光、粒子和档案抽取动画，同时保留全部内容与操作。

## 数据与集成

- PostgreSQL 数据必须原地兼容或通过可回滚迁移升级。
- 上传文件必须保留，公开附件只能暴露安全元数据，不得暴露 NAS 绝对路径。
- 已发布文章的现有 URL 必须保持可访问。
- Giscus 评论、Markdown、KaTeX、Mermaid、Markmap、代码高亮和 PDF 内容能力必须保留。
- NAS 的 standalone 部署方式必须保留。

## 权限基线

- 未登录用户只能读取已发布内容和公开资料。
- 普通成员只能修改自己的文章、资料、文件和便签。
- 管理员可以管理全站用户、内容、分类、照片、大事记、邀请码和站点配置。
- 页面可见性不是安全边界；Route Handler 和 Server Action 必须独立鉴权、授权和校验输入。

## 重构验收

每个阶段至少通过以下检查：

1. `pnpm format:check`
2. `pnpm lint`
3. `pnpm typecheck`
4. `pnpm test`
5. 对本阶段涉及的路由执行手工或端到端回归
