# 功能基线

本文档记录工程重构前必须保留的功能和行为。除非在变更记录中明确说明，否则重构后的页面、接口和数据迁移不得删除这些能力。

## 公共站点

| 领域         | 路由              | 必须保留的能力                                                                             |
| ------------ | ----------------- | ------------------------------------------------------------------------------------------ |
| 首页         | `/`               | 品牌入口、精选文章、文章日历、可拖拽知识分类图谱、竞赛航线、时间回声、照片、便签和成员预览 |
| 知识库       | `/knowledge-base` | 分类浏览、分类下多专栏、范围搜索、拼音/日期排序、文章详情、标签、附件、目录、上下篇和评论  |
| 竞赛         | `/competition`    | 竞赛分类、分类下多专栏、范围搜索、拼音/日期排序、文章列表和文章详情                        |
| 新闻与大事记 | `/archive`        | Milestone 星链、新闻多专栏入口、范围搜索、拼音/日期排序、新闻列表和对应详情                |
| 科协日常     | `/routine`        | 可检索照片墙、日常多专栏、文章搜索排序、图片查看和只读舱内留言                             |

| 聚合         | `/tags/[tag]`     | 按标签浏览已发布文章                                                                       |

### 首页 80m 知识潮汐

- 分类图谱必须由分类间的稳定稀疏连接组成，不得依赖单一中心节点；全部分类保持连通，每个节点最多四条连接。
- 水母节点可以拖拽，拖拽期间与其直接相连的实线和相邻节点必须高亮，连接线必须实时跟随位置变化。
- 空闲节点保持缓慢、不规则的自由移动；悬停或聚焦只让当前节点减速，选中节点固定位置但保留水母律动和呼吸微光。
- 图谱不得显示用于框定活动范围的边框、内圈或容器卡片；安全边界仍需阻止节点离开可操作区域。
- 点击分类只进行金色选中并打开附近文章列表，不直接导航；文章列表不得遮挡选中节点，每批最多五篇并保留“换一批”和“进入分类”。

### 首页 300m 竞赛航线

- 声纳区域最多展示七个互不重叠、位置稳定的竞赛分类，点击分类只切换探测模式，不直接导航。
- 声纳必须以黄铜、铜红、琥珀和暖白为主要信号色，与冷色海水背景形成明确对比；扫描包含可辨认的多层拖尾、方位刻度和中心脉冲，经过目标时显示短暂橙金边缘，选中目标保持暖金状态、中心方位线和锁定读数。
- 未选中分类时只展示已发布的精选竞赛文章；选中后只展示该分类下的已发布文章。
- 文章星图必须从十二种预设星座中稳定选择。星座暗星和连线始终展示，文章按最多七个锚点依次点亮；没有文章时不得隐藏星座骨架。
- 桌面端文章标题必须通过左右标注轨道和引线关联星点，每侧最多四条并执行纵向碰撞避让；移动端必须改用编号星点和双列文章信号清单。
- `300m / 竞赛航线` 必须保留为章节标识，并与 `80m / 知识潮汐` 使用相同字号；不得替换原有主标题。星图标题、副标题和文章标题不得继续使用当前的小字号。
- 桌面端选中分类后，声纳与星图之间必须出现暖色信号传输反馈；该装饰不可阻挡点击，也不可改变章节布局尺寸。
- 每批最多七篇并保留稳定游标“换一批”；分类模式必须提供“进入该竞赛”，默认模式提供竞赛中心入口。
- 加载、错误、空状态和文章批次变化不得撑高 300m 章节或改变首页章节坐标。

### 首页 900m 时间回声

- 标题置于章节左上方并适当缩小，右上角保留从上方向右侧展开的提亮回声纹路作为大事记时间轴。
- 大事记按时间从最外圈向内圈填充，同一圈必须沿弧线排列多个节点而非径向排列；首页最多读取最近十二条，后台列表按时间倒序维护。
- 回声圈必须保留流光效果；悬停或聚焦节点时更新共用的时间、标题与描述读数，鼠标悬停可产生受限粒子效果，点击可固定选择。
- 大事记读数区域必须位于右上回声区域的下沿内侧、观测台上方并避开水深导航，使用与深海背景有明确明度和色相差异的仪器配色；当前节点与读数之间保留可辨认的关联反馈。
- 新闻使用合上与展开的“科协档案夹”展示，初次进入保持合上状态；关闭时右侧必须展示网站内容统计和文章发表趋势。
- 统计观测台必须提供周、月、年视图，分别展示最近七天每日、最近三十天每日和最近十二个月每月的已发布文章数量。切换仅发生在客户端，不得重复请求首页数据。
- 观测台必须展示全站已发布文章、分类、成员、浏览量，以及各公共板块的分类数和已发布文章数；草稿不得进入公开统计。桌面端观测台与档案夹底部对齐，二者保留明确间距，并优先扩展观测台的图表区域。
- 档案夹展开后必须在标题下方居中并占据主要可用区域，可以覆盖大事记；每页新闻包含可进入完整稿件的标题、撰稿人、发布时间和正文摘要，并提供目录选择、翻页、合上档案夹和进入科协新闻的操作。
- 空新闻和空大事记必须提供明确状态；移动端不得出现标题、日志和时间轴重叠。
- 减少动态效果时必须停止流光、粒子和档案抽取动画，同时保留全部内容与操作。

### 首页 1800m 同行灯火

- 章节必须保留照片、便签和成员三个主要区域，并稳定收纳在单个动态视口内；加载、空状态和批次变化不得改变首页章节坐标。
- 照片墙固定预留一百一十六个与蒙版有实质交叠的槽位，并通过统一蒙版形成头部朝左上、躯干向右下收束、长胸鳍错位展开且尾鳍位于下方的跃起座头鲸轮廓；鲸头必须保留可辨识的嘴线与眼部留白。每批最多一百一十六张，蒙版必须彻底裁除边缘槽位位于轮廓外的部分，完全处于轮廓外的格位不得创建或计入照片槽位；超过时提供稳定循环的“换一批”，不足时只在鲸鱼内部保留空槽。照片必须支持悬停或聚焦放大、点击灯箱查看和键盘切换。
- 留言区域固定预留五张暖色纸质便签，采用稳定但不整齐的位置与角度。每批最多五条，超过时提供稳定循环的“换一批”，不足时保留空纸；完整留言管理继续通过 `/routine` 提供。
- 成员必须以线描生物光鱼的形式在章节底部双向游动，视觉语言与 `80m` 水母保持一致。姓名跟随对应鱼显示；悬停或聚焦时当前鱼暂停并高亮，共用信息区显示成员基本资料，点击进入成员主页。
- 移动端必须保留照片、五张便签和成员入口，不得通过隐藏整个区域解决空间不足。减少动态效果时停止游动和浮起动画，但保留批次切换、灯箱、信息显示与导航。

### 首页 4000m 海底星图

- 品质星图必须展示求真、协作、创造、传承和热爱五项品质，其中“热爱”的描述固定为“热爱世界，热爱知识”。

### 二级路由视觉继承

- 除首页以外的页面必须根据所属领域继承首页章节的配色、材质、标志性元素和主文案，但不得为了视觉统一复制首页的全屏布局、滚动吸附或高强度动画。
- `/knowledge-base`、`/search`、`/tags` 使用知识潮汐主题；`/competition` 使用竞赛航线主题；`/archive`、`/news`、`/events` 使用时间回声主题；`/routine`、`/friends` 和 `/dashboard` 使用同行灯火主题；`/admin` 使用海底星图主题；认证页面使用海面主题。
- `/archive` 标题下方必须首先展示由 `Milestone` 构成的星链：贯穿视口的深色底轨与黄铜细线依次串联八角航海星时间节点，节点保留冷白内芯、黄铜外缘、回声虚线环和坐标刻度；每个节点通过带锚点的折线连接到常显档案签。档案签必须展示按时间顺序生成的 `M-xx` 编号、日期、标题和描述，使用烟熏墨绿实色、左侧色标和右上切角，避免普通圆角卡片与高强度霓虹效果。桌面端档案签上下交错且数量较多时允许横向滚动，移动端改为纵向折线并保留同一视觉语言；星链始终按事件日期排列，不受新闻搜索和排序影响。
- 星链节点悬停时只允许增强当前航海星的光感、回声环和档案签边框，并让档案签产生不超过数像素的位移；不得改变节点或卡片尺寸。系统启用减少动态效果时必须停止回声环旋转和位移动画，同时保留全部日期、标题与描述。
- 星链下方依次展示新闻专栏入口和科协新闻列表。Archive 首页搜索只筛选普通新闻，新闻专栏页搜索只筛选当前专栏；两者均支持中文拼音首字母和发表日期排序。文章详情页不重复放置列表工具栏。
- `/routine` 必须按“照片墙、日常专栏与文章、舱内留言”顺序展示。照片墙每面最多十张公开照片，默认按上传时间从新到旧；支持描述关键词和起止上传日期搜索，翻墙按钮必须保留当前照片筛选条件。
- 桌面照片墙必须在稳定区域内使用十个错落的图钉位置，相片不得整齐排列；悬停或键盘聚焦照片时显示金色边框说明签。点击照片后在屏幕中央打开左右分栏浮窗，左侧完整展示照片，右侧以信纸样式展示描述、上传者和上传日期；无描述时显示“该照片暂时没有描述”，并保留上一张、下一张、关闭按钮及键盘方向键/Escape 操作。移动端改为稳定双列错落布局和上下分栏浮窗。
- `/routine` 和 `/routine/columns/[slug]` 的日常文章列表必须支持搜索、中文拼音首字母/发表日期排序和分页。日常文章可以加入零个或多个日常专栏，作者和管理员可在文章管理中调整关系。
- 公共 `/routine` 的舱内留言区域不得出现输入框或发布表单，只展示已有留言及有权限用户的删除操作；留言发布继续通过登录后的 `/dashboard/routine` 完成。
- 分类页和聚合页不得继续只使用通用卡片矩阵展示内容。知识分类必须具有潮汐节点或光点语义，竞赛分类必须具有声纳目标或航线语义，档案必须具有时间和编号语义，成员必须具有同行者或生物光信号语义。
- 文章详情必须根据 `KNOWLEDGE`、`COMPETITION`、`NEWS`、`EVENT` 和 `DAILY` 使用对应领域主题，同时保留正文、目录、附件、代码、公式、上下篇、评论和阅读统计等既有能力。
- 文章详情的正文阅读带必须与上方标题容器等宽。宽屏桌面的大纲固定悬浮在视口最右侧并在滚动期间保持可见，不得占用或压缩正文宽度；侧方空间不足时改用正文顶部的可折叠目录，避免遮挡内容。
- 知识主题标题带的右侧识别图形以稳定的三角形结构为主，不再使用水母轮廓。
- 文章正文提供默认、技术文档和论文阅读三种渲染风格；未显式选择时使用默认风格。
- Dashboard 与 Admin 可以自由使用侧栏、表格、表单、编辑器和状态读数，不要求复刻公共页面布局；操作区必须保持高信息密度、稳定尺寸、清晰焦点和移动端可用性。
- 首页与内页文案发生冲突时必须使用首页版本。章节主文案应集中维护，避免同一领域在不同页面产生不一致表述。
- 所有二级路由必须保留加载、空状态、错误状态、键盘焦点和 `prefers-reduced-motion` 支持；视觉重构不得修改现有 URL、权限边界、数据写入行为或公开内容筛选规则。

## 数据与集成

- PostgreSQL 数据必须原地兼容或通过可回滚迁移升级。
- 上传文件必须保留，公开附件只能暴露安全元数据，不得暴露 NAS 绝对路径。
- 所有已发布文章类型都可以提供匿名附件下载；草稿和归档附件保持私有。
- 日常文章可以不关联专栏，未归栏文章仍必须出现在日常文章列表和公开详情页。
- 普通新闻可以不加入新闻专栏，也可以同时加入多个新闻专栏；旧 `EVENT` 大事记文章不得加入新闻专栏。
- 日常文章可以不加入日常专栏，也可以同时加入多个日常专栏。
- 管理员可以在文章、用户、分类/专栏和邀请码页面执行单项或批量永久删除，危险操作必须二次确认。
- 成员上传的日常照片由 NAS 文件记录提供内联预览，旧 `imagePath` 照片继续兼容。
- 已发布文章的现有 URL 必须保持可访问；旧 `/news` 与 `/events` 地址永久重定向到 `/archive` 下的对应入口或详情。
- Giscus 评论、Markdown、KaTeX、Mermaid、Markmap、代码高亮和 PDF 内容能力必须保留。
- NAS 的 standalone 部署方式必须保留。

## 权限基线

- 未登录用户只能读取已发布内容和公开资料。
- 普通成员只能修改自己的文章、资料、文件、便签和照片，可以创建全站共享的分类与专栏。
- 普通成员不能停用或删除全站分类与专栏。
- 普通成员只能重命名自己创建的分类与专栏；管理员可以重命名全部项目。重命名不改变 slug。
- 管理员可以管理全站用户、内容、分类、专栏、照片、大事记、邀请码和站点配置。
- 页面可见性不是安全边界；Route Handler 和 Server Action 必须独立鉴权、授权和校验输入。

## 重构验收

每个阶段至少通过以下检查：

1. `pnpm format:check`
2. `pnpm lint`
3. `pnpm typecheck`
4. `pnpm test`
5. 对本阶段涉及的路由执行手工或端到端回归
